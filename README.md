# SMSeguro (ZeroFraud)

## Descripción
Plataforma diseñada para combatir el fraude cibernético y el smishing en México mediante redes sociales y apps de mensajería. Su objetivo es proteger a usuarios vulnerables, como adultos mayores y estudiantes, centralizando la verificación de amenazas, el reporte comunitario y la consulta pública de indicadores de riesgo.

## Detalles Técnicos
- **Versión de Xcode:** Desarrollo nativo en Swift y UIKit.
- **Modelo de iPhone (Simulador):** Pruebas visuales y maquetación configuradas para iPhone 17 Pro.
